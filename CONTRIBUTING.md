# 🤝 Hamkorlik Qoidalari

Bu loyiha **ochiq kod** va **boshqa AI-lar** ham qatnashishi mumkin.

## Asosiy Qoidalar:
1. **Modular kod** - har bir komponent mustaqil
2. **Yopiq emas** - boshqa AI'lar o'zgartrishi mumkin  
3. **AI Critic sistema** - kod sifati nazorat
4. **Hujjat majbur** - komponent nima qilishini tushunarli

## Commit Format
```
feat(module): feature
fix(module): bug fix
refactor(module): code change
docs(module): documentation
```

## Pre-commit Checklist
- [ ] Kod lokal'da ishlaydi
- [ ] Tests o'tdi
- [ ] Linting o'tdi
- [ ] Dokumentatsiya yangilandi
